## 📖 درباره افزونه

**کدتخفیف‌ساز پیشرفته ووکامرس** یک افزونه WordPress/WooCommerce برای ساخت و مدیریت کدهای تخفیف پیشرفته و انعطاف‌پذیر است.

این افزونه سیستم استاندارد کدهای تخفیف ووکامرس را گسترش می‌دهد و امکان تعریف چندین قانون تخفیف در یک کد تخفیف را فراهم می‌کند.

قوانین تخفیف می‌توانند بر اساس موارد مختلفی مانند:

- محصولات مشخص
- دسته‌بندی محصولات
- برند محصولات
- سایر محصولات واجد شرایط
- روش‌های ارسال

تنظیم و اعمال شوند.

> این پروژه یک افزونه مستقل و شخص ثالث برای WooCommerce است.

## 🧠 نحوه عملکرد

افزونه سیستم استاندارد Coupon در WooCommerce را با یک موتور تخفیف مبتنی بر قوانین گسترش می‌دهد.

هر کد تخفیف می‌تواند شامل چندین قانون مختلف باشد که مشخص می‌کنند:

- کدام محصولات شامل تخفیف شوند
- کدام دسته‌بندی‌ها شامل تخفیف شوند
- کدام برندها شامل تخفیف شوند
- نوع تخفیف چه باشد
- مقدار تخفیف چقدر باشد
- آیا محصولات واجد شرایط دیگر نیز تخفیف دریافت کنند
- آیا ارسال رایگان فعال شود

### مثال

یک کد تخفیف می‌تواند به‌گونه‌ای تنظیم شود که:

- 🟢 روی محصولات مشخص **۲۰٪ تخفیف** اعمال کند
- 🔵 روی یک دسته‌بندی خاص **۱۰٪ تخفیف** اعمال کند
- 🟣 روی محصولات یک برند خاص **مبلغ ثابتی تخفیف** اعمال کند
- 🟠 روی سایر محصولات واجد شرایط تخفیف متفاوتی اعمال کند
- 🚚 امکان **ارسال رایگان** را فعال کند

تمام قوانین از طریق پنل مدیریت WordPress قابل ایجاد، ویرایش و مدیریت هستند.

## 📦 نصب

### روش اول — نصب از GitHub Release

1. وارد بخش **[آخرین Release](https://github.com/alirezasayadi/woocommerce-advanced-discount-builder/releases/latest)** شوید.
2. فایل ZIP افزونه را دانلود کنید.
3. وارد پیشخوان WordPress شوید.
4. به **افزونه‌ها ← افزودن ← بارگذاری افزونه** بروید.
5. فایل ZIP دانلودشده را انتخاب کنید.
6. افزونه را نصب کنید.
7. افزونه را فعال کنید.

> قبل از استفاده از افزونه، مطمئن شوید WooCommerce نصب و فعال شده است.
